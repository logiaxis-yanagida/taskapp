# タスク管理アプリ（音声入力・ワンタップ操作）

自分用のタスク管理ツールです。文字入力を最小限にし、話しかけるか数タップでタスクを登録できます。

## 起動方法

1. `起動.bat` をダブルクリックします（Python 3 が必要です）。
2. ブラウザ（Chrome または Edge）で `http://localhost:8787/` が開きます。
3. 黒いコマンド画面を閉じると停止します。

ブラウザの localStorage にデータを保存するため、同じ PC・同じブラウザで開けば前回の内容が残ります。

## 使い方

### タスクを登録する

- **音声で**: マイクボタンを押して話します。例「明日までに請求書送付、優先度高」。
  話した内容から「タスク名」「期限」「優先度」「カテゴリ」「繰り返し」を自動で振り分け、登録します。
- **文字で**: 入力欄に打って Enter。音声と同じ解析が効きます。
- 解析結果はチップで表示されます。間違っていればチップをタップして選び直せます。

### 話し方の例

| 話す内容 | 結果 |
| --- | --- |
| 明日までに請求書送付 優先度高 | 期限=明日、優先度=高 |
| 来週の水曜日までに LOGIAXIS の提案書を作る 至急 | 期限=来週水曜、カテゴリ=LOGIAXIS、優先度=高 |
| 毎週金曜に週報を書く 仕事 | 繰り返し=毎週、期限=次の金曜、カテゴリ=仕事 |
| 15日に家賃振込 私用 | 期限=今月15日（過ぎていれば来月）、カテゴリ=私用 |
| 今週中に見積もり | 期限=今週の日曜 |
| 明後日の朝9時に 群馬銀行の返済予定表を確認 | 期限=明後日、時刻=9:00（カレンダーには 9:00〜9:30 の予定として登録） |
| いつか本を読む | 優先度=低、期限なし |

### 一覧の操作

- 「今日」「予定」「すべて」「完了」タブで切り替えます。
- チェックで完了。繰り返しタスクは次回分が自動で作られます。
- 期限・優先度・カテゴリは一覧上でタップして変更できます。
- 削除は「元に戻す」付きです。

### Google カレンダー連携

期限のあるタスクを Google カレンダーに登録できます。時刻なしなら終日予定、「朝9時に」のように時刻を指定したタスクはその時刻から30分の予定になります。初回のみ設定が必要です。
登録方式は設定画面で選べます（既定は「登録後に確認する」）。

- 登録後に確認する: タスク登録直後に「カレンダーに追加しますか？」が出て、「追加」を押したときだけ登録します。
- 自動で登録する: 期限付きタスクを登録した瞬間にカレンダーへ登録します。
- 手動: タスク行のカレンダーボタンを押したときだけ登録します。

一度カレンダーに登録したタスクは、期限変更・完了・削除がカレンダー側にも反映されます。
手順は [docs/Googleカレンダー連携_設定手順.md](docs/Googleカレンダー連携_設定手順.md) を参照してください。
設定前でも、タスク行のカレンダーボタンから Google カレンダーの予定作成画面を開けます。

### バックアップ

設定画面から JSON でエクスポート・インポートできます。ブラウザのデータを消す前や、別の PC に移すときに使います。

## ファイル構成

```
index.html          画面
css/style.css       スタイル
js/app.js           画面の制御・カレンダー同期
js/store.js         データ保存（localStorage）
js/parser.js        日本語の解析（期限・優先度・カテゴリ・繰り返し）
js/voice.js         音声入力（Web Speech API）
js/gcal.js          Google カレンダー API
js/dateutil.js      日付ユーティリティ
tests/              node --test で実行する単体テスト
docs/               設定手順
SPEC.md             仕様・モジュール契約
```

## テスト

```bash
node --test
```

Google カレンダーの実際の登録は OAuth クライアント ID を設定した環境でのみ動作します。設定前は単体テスト（モック）のみで検証しています。
